# SYS – Struktur Root (3‑6‑9 Engine)

SYS ist die Struktur‑Ebene des 3hit90‑Systems.  
Während **[TEM](ca://s?q=TEM_Root_erklaeren)** die Zeit erzeugt, hält SYS die **Form**,  
die **Orbit‑Stabilität**, die **NC‑Engine** und die **System‑Geometrie**.

---

## SYS‑Schichten (3‑6‑9)

### **SYS3 – obere Struktur (XyX.js)**
- **IN**
- **CORE**
- **OUT**

Diese drei bilden die Start‑Struktur des Systems.

### **TEM6 – Zeit‑Bewegung (TET + RIZ)**  
- **TET (+T)** → ESSO, ROLLER, KASSE  
- **RIZ (−T)** → DOOR, DOO, SHELL  

Diese sechs fallen diagonal auf TEM.

### **SYS9 – untere Struktur (NC.9y9.json)**  
- Orbit  
- Station  
- Korridor  
- NC‑Engine  
- Autopilot  
- Prefetch  
- Stabilisierung  
- SYS‑IN  
- SYS‑OUT  

Diese neun schließen die Struktur.
